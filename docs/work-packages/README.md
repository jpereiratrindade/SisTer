# Pacotes de Trabalho do SGE-SisTer

Pacotes de trabalho conectam necessidades técnicas a arquitetura, contratos,
evidências e gates. Eles são a unidade de planejamento da fase Alfa em diante.

Antes de implementar uma mudança relevante, registre ou atualize o pacote
correspondente com:

- objetivo arquitetural;
- estágio alvo;
- ADRs relacionadas;
- contratos afetados;
- evidências esperadas;
- checks ou gates impactados;
- riscos e rollback;
- responsável técnico ou papel responsável.
