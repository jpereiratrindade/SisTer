# `sister.relation/1.0.0`

> **Status: DRAFT / NOT RUNTIME-NORMATIVE**

Contrato candidato do ARC-01 para descrever por que participantes se compõem,
quais papéis assumem, quais capacidades podem solicitar e onde permanecem as
fronteiras de autoridade.

Uma relação não define topologia nem obriga intermediação. Este draft não
autoriza execução, não altera persistência e não é interpretado pelo runtime.

## Artefatos

- `relation.schema.json`: participantes, papéis, concessões, autoridades,
  ciclo de vida e política de evidência;
- `examples/nexo-praxis-method-assessment.json`: relação direta candidata;
- `examples/invalid-relation-with-intermediary.json`: prova negativa de que um
  intermediário técnico não integra a semântica da relação.
