# Governança de Engenharia

Modelos e templates do SGE-SisTer.

Este módulo governa decisões, evidências, aprovações e promoções sem substituir
os domínios dos subsistemas.

O planejamento evolutivo inicial está descrito em
[`docs/planning/PDE-SISTER.md`](../../docs/planning/PDE-SISTER.md) e é
materializado pelo WP-SGE-PLAN-01. A implementação atual é consultiva e de
decisão controlada; não constitui Kanban, promoção de maturidade ou autorização
de release.
